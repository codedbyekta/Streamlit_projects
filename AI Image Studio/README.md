# 🎨 AI Image Studio

An interactive **AI image generation app** built with Streamlit and the Pollinations AI image API.

### ✨ Features

* 🎨 Multiple art styles
* 📐 Custom image width and height
* ✨ Magic Enhance option
* 🎲 Surprise Me prompt generator
* 🖼️ Real-time image generation
* ⬇️ Download generated images

### 🛠️ Tech Stack

**Python | Streamlit | Requests | Pollinations AI**

### 🚀 Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

### 📌 Project Highlights

This project demonstrates **AI API integration, prompt engineering, dynamic UI controls, random prompt generation, image generation, and file downloading using Streamlit**.
