# 🧠 Life-OS — Wellbeing Dashboard

Life-OS is a Streamlit dashboard that turns raw screen-time logs into a
professional, SaaS-style analytics view — and then hands that data to
**Google Gemini**, acting as a brutal-but-fair productivity coach, to turn
numbers into specific, actionable advice.

## What it does

- Loads a 14-day synthetic screen-time log (`screentime.csv`) covering apps
  like Instagram, YouTube, VS Code, LeetCode, and WhatsApp.
- Lets you pick any day and set a personal daily screen-time goal.
- Shows a KPI row (total usage, most-used app, goal difference), a 14-day
  trend chart, and category/app breakdowns for the selected day.
- Aggregates the selected day's data into a clean JSON summary and sends
  **only that summary** (never the raw dataframe) to Gemini.
- Gemini returns a structured coaching report: a verdict, the biggest
  time-wasting categories with real numbers, concrete real-world
  replacement activities, and an estimate of reclaimable time.
- Includes a **Shareable Accountability Link**: the selected day's stats are
  encoded into the URL via `st.query_params`, so you can share a link and
  anyone who opens it sees that day's screen-time number.

## Tech stack

| Layer | Tool |
|---|---|
| UI / App framework | [Streamlit](https://streamlit.io) |
| Data handling | [Pandas](https://pandas.pydata.org) |
| AI coaching | [Google Gemini API](https://ai.google.dev) (`gemini-1.5-flash`) |
| Secrets | `python-dotenv` + `.env` |

## The Gemini coaching feature

The dashboard never sends Gemini the raw DataFrame. Instead, `app.py`:

1. Filters the data to the selected day.
2. Aggregates `Minutes_Used` by `Category` and by `App_Name`.
3. Packages the totals, the daily goal, and the goal difference into a
   small JSON object.
4. Inserts that JSON into a prompt that instructs Gemini to act as a
   direct, no-nonsense coach who must cite the actual numbers, name the
   worst time-wasting categories, propose specific real-world
   replacements (not "use your phone less"), and estimate reclaimable
   time per day/week.
5. Renders Gemini's markdown response in the "Life-OS Coach" section,
   with `st.info` / `st.warning` / `st.error` chosen based on how far over
   goal the day was.

## Running locally

1. **Clone the repo and enter the folder**
   ```bash
   git clone <your-repo-url>
   cd life-os
   ```

2. **Create a virtual environment and install dependencies**
   ```bash
   python -m venv venv
   source venv/bin/activate    # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. **Add your Gemini API key**
   ```bash
   cp .env.example .env
   # then edit .env and set GEMINI_API_KEY=your_actual_key
   ```
   Get a key from [Google AI Studio](https://aistudio.google.com/app/apikey).

4. **Run the app**
   ```bash
   streamlit run app.py
   ```
   The app opens at `http://localhost:8501`.

## Deploying

1. Push this repo to a **public GitHub repository** (make sure `.env` is
   *not* included — `.gitignore` already handles this).
2. Deploy on [Streamlit Community Cloud](https://streamlit.io/cloud) (or
   any platform that supports Streamlit).
3. In the deployment platform's **Secrets** manager, add:
   ```
   GEMINI_API_KEY = "your_actual_key"
   ```
4. Verify the live app loads the CSV, renders charts, and that the
   "Generate Coaching Report" button returns a Gemini response with no
   API-key errors.

## Notes

- `screentime.csv` is synthetic data generated by `generate_data.py` for
  demo purposes — swap in your own exported screen-time data with the same
  four columns (`Date`, `App_Name`, `Category`, `Minutes_Used`) to
  personalize it.
- The app degrades gracefully if `GEMINI_API_KEY` is missing or the
  `google-genai` package isn't installed — it shows a clear warning
  instead of crashing.
- **SDK**: the app uses Google's current unified `google-genai` SDK
  (`from google import genai`, `genai.Client(...)`), not the older
  `google-generativeai` package, which Google has deprecated.
- **Model availability**: Google retires Gemini model versions periodically
  (all `gemini-1.5-*` models are fully shut down as of mid-2026). `app.py`
  tries a short list of current models (`gemini-2.5-flash`,
  `gemini-2.5-flash-lite`, `gemini-3.6-flash`) in order and falls back
  automatically if one isn't available for your key. If you still get a 404,
  run this to see what your key actually supports, then edit the
  `candidate_models` list in `call_gemini()`:
  ```python
  from google import genai
  client = genai.Client(api_key="YOUR_KEY")
  for m in client.models.list():
      print(m.name)
  ```
