# 🌌 Upgrading the AI Multiverse

A Streamlit + Gemini AI chatbot with **creative AI personalities, adjustable intensity, sidebar settings, chat bubbles, and dynamic avatars**.

## ✨ Features

* 🎭 11 different AI personalities
* 🎚️ Personality **Intensity Level (1–10)**
* 📌 Settings moved to the sidebar
* 💬 Streamlit native chat UI
* 🤖 Dynamic emoji avatars
* 🧠 Gemini API integration
* ⚡ Prompt dynamically adapts to personality and intensity

## 🛠️ Tech Stack

* Python
* Streamlit
* Google Gemini API
* `python-dotenv`

## 🚀 Run Locally

```bash
python -m venv venv
venv\Scripts\activate
pip install streamlit google-genai python-dotenv
streamlit run app.py
```

Create a `.env` file:

```env
GEMINI_API_KEY=your_api_key_here
```
