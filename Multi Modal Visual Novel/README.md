# 🎮 AI Multi-Modal Visual Novel

An interactive AI visual novel built with **Streamlit** and **Google Gemini**. The AI generates the story, images, and narration based on the user's choices.

### ✨ Features

* 📖 AI-generated interactive stories
* 🎭 Multiple story genres
* 🎨 Multiple art styles
* 🖼️ AI-generated scene images
* 🔊 Text-to-speech narration
* 🎯 Player choices that continue the story
* 📚 Story history

### 🛠️ Tech Stack

**Python | Streamlit | Google Gemini | Pollinations AI | gTTS | Pillow**

### 🚀 Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

### 📌 Project Highlights

This project demonstrates **Generative AI, prompt engineering, JSON-based LLM output, image generation, text-to-speech, session state, and multi-modal AI integration**.
